# Сайт Разом KW: беклог v2.0

Базова версія: **v1.0** (тег `v1.0`). 89 спеціалістів у 13 категоріях, головна, каталог, форма заявки, школа, відгуки, адмінка, CRM, пошта в адмінці, події з Facebook, i18n (укр/англ), JSON-LD і OG-теги, sitemap/robots, тести (vitest і Playwright), 4 GitHub Actions workflow.

## З чим порівнювали

Загальні практики каталогів місцевих послуг (огляди joinit.com, turnkeydirectories.com, webtonic.io, baymard.com), плюс огляд власного коду. Окремого порівняння з конкретними українськими громадськими сайтами не робили: пошук цих сайтів не спрацював (ліміт пошукового API), тож це слід доповнити вручну.

Типова практика сильних каталогів: карта, позначка «перевірено» з датою, відгуки, механізм «це моя картка», регулярне підтвердження актуальності, окрема сторінка на кожну послугу для пошуку, швидкість і мобільна версія.
