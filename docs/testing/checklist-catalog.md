# Чек-лист: Каталог спеціалістів

## Відображення
- [ ] Всі спеціалісти з бази завантажуються
- [ ] Картки показують коректні дані (ім'я, категорія, ціна, локація)
- [ ] Фото завантажується або показується плейсхолдер
- [ ] Instagram-лінк активний (якщо є)
- [ ] Лінки відкриваються в новій вкладці (_blank)

## Фільтри
- [ ] Фільтр за категорією:
  - [ ] Показує унікальні категорії
  - [ ] Вибір категорії оновлює список
  - [ ] Мультивибір працює
- [ ] Фільтр за локацією:
  - [ ] Показує унікальні локації
  - [ ] Вибір локації оновлює список
  - [ ] Мультивибір працює
- [ ] Кнопка "Очистити фільтри" видаляє всі вибори
- [ ] Пошук по імені (якщо реалізовано):
  - [ ] Працює в режимі реального часу
  - [ ] Регістр-незалежний пошук
  - [ ] Показує результати для частини імені

## Сортування
- [ ] Сортування за ціною (зростання/спадання)
- [ ] Сортування за імям (А-Я)
- [ ] За замовчуванням: сортування логічне (наприклад, за датою додавання)

## Мобільна адаптивність
- [ ] На телефоні: 1 картка на рядок
- [ ] На планшеті: 2 картки на рядок
- [ ] На десктопі: 3+ картки на рядок
- [ ] Фільтри на мобільному: горизонтальний скрол або dropdown
- [ ] Карткам хватає місця, текст не обрізається

## Пагінація (якщо є)
- [ ] Перша сторінка завантажується автоматично
- [ ] Кнопка "Далі" працює
- [ ] Кнопка "Назад" працює
- [ ] Кількість елементів на сторінку: 10-20
- [ ] При прокручуванні вниз: автоматичне завантаження наступної сторінки (infinite scroll)

## Edge cases
- [ ] Спеціаліст без фото: показується іконка/плейсхолдер
- [ ] Спеціаліст без Instagram: посилання не показується, текст замість нього
- [ ] Дуже довге імя: текст переноситься або скорочується з (...)
- [ ] Вибір фільтра, що не дає результатів: "Спеціалістів не знайдено"
- [ ] Велика база (1000+ записів): перформанс залишається гарним

## Контакт зі спеціалістом
- [ ] Клік на Instagram: відкривається в новій вкладці
- [ ] Клік на Telegram (якщо є): відкривається мобільне додатково або веб
- [ ] Клік на телефон: розпочинається виклик/SMS (на мобільному)
- [ ] Copy-to-clipboard для контактів (якщо реалізовано)

## Доступність
- [ ] Фільтри мають лабели для екранних читачів
- [ ] Картки структуровані семантично (card, button, link)
- [ ] Колір не єдиним способом передавання інформації
- [ ] Всі інтерактивні елементи доступні з клавіатури
