# Чек-лист: Українська школа (Ukrainian School Page)

Цей чек-лист містить базові та розширені перевірки для нової сторінки української школи, а також перевірки навігації на цю сторінку.

## 1. Навігація з Головної Сторінки
- [ ] Кнопка в хедері (Header): Перевірити наявність кнопки "Українська школа" поруч з посиланням на "Каталог" у головному навігаційному меню.
- [ ] Блок школи на головній сторінці:
  - [ ] Наявність кнопки "Докладно про школу"
  - [ ] Адаптивне вирівнювання кнопки: по центру на мобільних пристроях (< 768px), по лівому краю на десктопі (>= 768px)
  - [ ] Візуальний поділ: достатній відступ між кнопкою школи та наступною секцією подій громади
  - [ ] Відсутність дублювання тексту в описі суботньої школи
- [ ] Перехід за посиланнями: Клік на будь-яке з цих посилань має вести на `/school.html`.

- [ ] Навігація назад: Можливість повернутися на Головну або Каталог через хедер.

- [ ] Перемикач мови (#lang-toggle):
  - [ ] Присутній у верхньому меню з прапорцем поточної мови (SVG).
  - [ ] При кліку змінює мову на English (`lang="en"`).
  - [ ] Заголовок вкладки змінюється на "Ukrainian School Waterloo | Razom KW".

  - [ ] Навігаційні посилання в хедері перекладаються ("Home", "School").
  - [ ] Зовнішні посилання та контакти зберігають коректні URL.
- [ ] Збереження вибору: Мова зберігається після оновлення сторінки та при переході між сторінками сайту.
