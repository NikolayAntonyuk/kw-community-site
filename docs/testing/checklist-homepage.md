# Чек-лист: Головна сторінка (Homepage)

## Hero-секція
- [ ] Відео завантажується без затримок
- [ ] Текст відображається поверх відео
- [ ] Переходи тексту плавні при скролі
- [ ] Мобільний вигляд: текст читається, видео масштабується
- [ ] На планшеті: компонування залишається читабельним

## Каталог спеціалістів (видимий після скролу)
- [ ] Список спеціалістів завантажується
- [ ] Кожна картка показує: фото, імя, категорія, локація, ціна
- [ ] Картки адаптуються до розміру екрана
- [ ] На мобільному: картки в одну колону
- [ ] На планшеті: 2 колони
- [ ] На десктопі: 3+ колони

## Пошук/Фільтрування
- [ ] Пошук за імям працює
- [ ] Фільтр за категорією працює
- [ ] Фільтр за локацією працює
- [ ] Багатофільтр (категорія + локація) працює
- [ ] При порожньому результаті показується повідомлення "Не знайдено"
- [ ] Фільтри очищуються кнопкою "Reset"

## Навігація
- [ ] Меню зверху липке (sticky) при скролі
- [ ] Посилання меню мають активний клас
- [ ] На мобільному: меню гамбургер розкривається
- [ ] На мобільному: меню закривається при клацанні на посилання

## Перформанс
- [ ] Сторінка завантажується < 3 сек (CLS < 0.1)
- [ ] Немає макета зміщення (Layout Shift)
- [ ] Скролінг плавний (60 FPS)

## Контакти/СОЦ мережі
- [ ] Іконки соцмереж відображаються коректно
- [ ] Посилання відкриваються в новій вкладці
- [ ] Форма "Зв'язатися з нами" (якщо є) працює

## Доступність
- [ ] Контрастність текст/фон достатня
- [ ] Кнопки та посилання мають fokuс стилі
- [ ] Форми мають label'и для екранних читачів
